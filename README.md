Project Name: Bajar Dor


Description: Bajar Dor is a web application that helps users check daily market prices in Bangladesh. User can explore the prices og daily products and see products details, current prices and price changes. Users can create an account and sign in to access the websites features.


Technologies Used:
1. Next.js
2. React.js
3. TypeScript
4. Tailwind CSS 
5. DaisyUI
6. Better Auth
7. MongoDB
8. API
9. React Icons
10. Git & GitHub


Features(minimum 5):
1. Product Categories
2. Product Details
3. Price Sorting
4. Daily Market Prices
5. User Profile
6. User Sign Up & Sign In
7. Responsive Design
